# Rubicon Python training

This repository contains practical Python programs covering **basic Python concepts, Object-Oriented Programming, exception handling, file handling, modules, NumPy, Pandas, and SQLite database operations**.

## Topics Covered

### 1. Python Basics

* Basic Python syntax and program execution
* String operations and built-in functions
* Simple calculations and user input

### 2. Object-Oriented Programming

* **Encapsulation:** Demonstrates private attributes and methods for controlled access to data.
* **Inheritance:** Demonstrates how a child class inherits functionality from a parent class.

### 3. Exception Handling

Demonstrates handling common Python exceptions including:

* `ZeroDivisionError`
* `ValueError`
* `TypeError`
* `IndexError`
* `KeyError`
* `FileNotFoundError`
* `NameError`
* `AttributeError`

It also demonstrates **custom exceptions** for age, bank balance, marks, password, and number validation.

### 4. File Handling

The file-handling program demonstrates:

* Creating files
* Writing data
* Reading complete files
* Reading individual lines
* Reading all lines
* Appending data
* Checking whether a file exists
* Checking file size
* Deleting files

### 5. Python Modules

Demonstrates importing and using functions and constants from a custom Python module.

### 6. NumPy

A student marks analyzer demonstrates:

* NumPy arrays
* Array properties
* Indexing and slicing
* Vectorized operations
* Sum, average, maximum, minimum
* Standard deviation

### 7. Pandas

The Pandas program demonstrates student data analysis using DataFrames:

* Creating DataFrames
* Viewing records
* Filtering data
* Adding columns
* Calculating final marks
* Assigning grades
* Sorting
* Grouping by department
* Finding the topper
* Exporting results to CSV

### 8. SQLite Database

The student database project uses SQLite to:

* Connect to a database
* Create a students table
* Insert records
* Retrieve records
* Filter using `WHERE`
* Sort using `ORDER BY`
* Find individual records
* Update records
* Delete records
* Handle transactions and rollback
* Close the database connection

## Technologies Used

* Python
* NumPy
* Pandas
* SQLite
* CSV

## Purpose

This repository is designed as a **Python learning and practice project**, demonstrating programming fundamentals and commonly used Python libraries through simple, practical examples.
